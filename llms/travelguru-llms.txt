# Travelguru

> Travelguru was an Indian online hotel-booking brand. Yatra.com acquired a 100% stake in Travelguru in July 2012, and the brand has since been folded into Yatra: travelguru.com (and the Travel Partner Web hotel extranet at travelpartnerweb.com) now 301-redirect to https://www.yatra.com/. Travelguru publishes no standalone website, developer portal, or API surface today.

Generated by the API Evangelist enrichment pipeline on 2026-07-21 from apis.yml and live probes of the Travelguru web surface. Travelguru is tracked in the API Evangelist network as a Battery Ventures portfolio company.
